# Jobs — one page each, one session each

Each file here is the whole brief for one session. Start a fresh session, say *"do docs/jobs/<file>"*, and it reads
`platform/psa-spine/CLAUDE.md` and the brief, does the job, commits, adds one paragraph to the runbook, and closes.
When a job is done, its file gets `Status: done <date> <commit>` on its first line and stays as the record.
